Settings.

Configure your workspace, security and AI preferences.

Workspace information
Basic details about your organization's workspace.
Workspace preferences
Control how users can join and interact with the workspace.
Allow public sign-ups When enabled, anyone with the workspace URL can request access.
Guest access Allow temporary view-only access via share links.
Auto-archive inactive users Automatically archive users inactive for more than 90 days.
Authentication
Configure how users sign in to the workspace.
Two-factor authentication (2FA) Require 2FA for all users when signing in. Strongly recommended.
Single sign-on (SSO) Allow users to sign in via your organization's identity provider.
Session timeout Automatically sign out users after 30 minutes of inactivity.
Access rules
Restrict access based on network, device, and other factors.
Block suspicious locations Automatically block sign-ins from flagged regions or unusual countries.
Restrict to managed devices Only allow access from company-managed devices.
API keys
Manage API keys used for integrations and automation.
Danger zone
Irreversible actions. Please proceed with caution.
Force logout all sessions Sign out all users from all devices immediately.
Delete workspace Permanently delete this workspace and all its data.
AI model & retrieval
Configure how the AI answers questions from your documents.
Show source citations Always include the source document and page for AI answers.
Semantic search Use vector embeddings for smarter search results.
Allow AI to answer with uncertainty If the AI is unsure, it will say so instead of guessing.
Email notifications
Choose which events trigger email alerts.
New user invited Notify admins when a new user is invited to the workspace.
Document uploaded Notify relevant users when new documents are uploaded.
Suspicious activity Immediate alerts for failed logins and unusual access patterns.
Weekly activity digest Summary of workspace activity every Monday morning.
Delivery preferences
Where and how you want to receive notifications.

Delete workspace

This action is permanent and cannot be undone.

All documents, users, audit logs, and workspace data will be permanently removed.
